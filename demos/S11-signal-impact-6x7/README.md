# S11 Creator Impact / 真人高密度大字 — 6:7

This demo exercises the flagship `S11` system on a model-test topic.

- Platform: WeChat Channels / 视频号
- Canvas: 1080 × 1260 PNG
- Hook: `Fable 5.1 真能打吗？`
- Reading order: huge hook → face → large count → proof → check items
- Palette: pale yellow, white, near-black, green checks, coral label
- Signature components: enormous outlined hook, real cutout, topic-related interface wall, tilted benchmark card, thick arrow, and three check items
- Density rule: headline uses 35%–45% of vertical height and the person uses 35%–55% of the canvas. Fill gaps with verified counts, checks, arrows, and proof—not unrelated decoration.
- Copy rule: Chinese is the primary language; English is reserved for official model names. Supporting claims must be traceable to supplied evidence.

The portrait uses the supplied cutout pixels—not a regenerated person. The checkerboard is converted into transparency, then the person is scaled as a foreground shape that bleeds off the right and bottom edges. The supplied benchmark is reused twice: a softened, darkened enlargement establishes the topic-related background, while a sharp crop acts as evidence. The portrait, mark, and benchmark are exact-use inputs supplied for this design exercise. The layout, type treatment, evidence card, signal marks, and palette system are original to this repository.

Run:

```bash
python3 build_demo.py
python3 ../../create-social-thumbnails/scripts/verify_thumbnail.py preview.png --platform wechat-channels
```
