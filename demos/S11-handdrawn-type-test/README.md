# S11 手绘标题分层测试

这是 `Creator Impact / 真人高密度大字` 的字体实验，不是另一套风格。

- 画布：视频号 1080 × 1260，6:7。
- 保持不变：布局、人物、背景、榜单卡、箭头、颜色和文案层级。
- 主标题：使用粗犷的手绘马克笔字形、轻微不齐基线和人工作笔边缘。
- 大数字：使用较克制的同类手绘节奏。
- 小字：副标题、模型名、数据、勾选项和证据标签保持规整粗黑体。

结论：手绘感应集中在主标题和大数字。全部文字手绘会降低数据与小标签的可读性。
