# S01 — Warm Handwritten Collage, 6:7

![S01 thumbnail preview](preview.png)

## Classification / 风格归类

- Primary / 主风格：`S01 Warm Handwritten Collage / 暖白手写拼贴`
- Secondary trait / 辅助特征：`S02 Face-led High CTR / 人物高点击`
- Canvas / 画布：1080 × 1260 (`6:7`)
- Intended placement / 目标场景：WeChat Channels-style vertical cover / 视频号式竖版封面

The primary ID is `S01` because the cover is defined by warm ivory paper, navy hand-drawn lettering, coral and blue brush accents, a real UI collage, and a white-to-transparent transition below the title. The large cutout person adds the `S02` click-driving trait but does not replace the underlying collage system.

主编号使用 `S01`：暖白纸张、深蓝手写字、橙蓝笔刷、真实 UI 拼图以及标题下方的白色渐变共同决定了基础风格。右侧大比例人物带来 `S02` 的高点击特征，但属于辅助层。
