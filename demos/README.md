# Demos / 示例

This directory is reserved for finished, reproducible thumbnail examples. It is intentionally empty of visual assets in the initial release.

本目录用于后续添加可复现的封面案例。首个版本不放假图，也不把用户私有素材直接发布到仓库。

Each demo should contain:

- `README.md`: goal, prompt, platform, dimensions, layout decisions, and reproduction steps;
- `input/`: assets that are owned, licensed, or explicitly redistributable;
- `output/`: final exported thumbnail;
- `LICENSE-ASSETS.md`: author/source, license, attribution, model release or likeness note where relevant;
- optional `layout.json` or editable source file.

每个 Demo 应记录素材来源和授权状态。含人物、品牌、字体、第三方界面或生成式素材时，必须分别说明；不要仅凭本仓库采用 MIT License 就宣称 Demo 素材“可商用”。
